# Claude Code ショートカット / キーバインド

対象バージョン: Claude Code 2.1.226(Linux / WSL 環境で確認)

> 記載は実行バイナリ内のデフォルトキーバインド定義から抽出したもの。
> Mac では `alt` → `option`、一部 `ctrl` → `cmd` に読み替える。

---

## 最頻出(これだけ覚えれば足りる)

| キー | 動作 |
|---|---|
| `Shift+Tab` | **モード切替**(通常 → 自動承認 → Plan モード をサイクル) |
| `Esc` | 実行中の処理をキャンセル |
| `Esc` `Esc`(2回) | **`/rewind`** を開く。過去の任意の地点までコード・会話を巻き戻す |
| `Ctrl+C` | 中断(2回で終了) |
| `Ctrl+D` | セッション終了 |
| `Ctrl+O` | **トランスクリプト表示**(省略された出力の全文を見る) |
| `Ctrl+T` | TODO リストの表示切替 |
| `Ctrl+R` | 過去のプロンプト履歴を検索 |
| `↑` / `↓` | プロンプト履歴を遡る / 進む |

`Esc` `Esc` は入力欄にテキストがある場合は**入力のクリア**になる。
入力が空のときに巻き戻し(メッセージセレクタ)が開く。

---

## 入力欄(Chat)

| キー | 動作 |
|---|---|
| `Enter` | 送信 |
| `Ctrl+J` | 改行(送信せず) |
| `Shift+Enter` | 改行(`/terminal-setup` で有効化した場合) |
| `\` + `Enter` | 改行(上記が使えない端末でのフォールバック) |
| `Ctrl+L` | 入力欄をクリア |
| `Ctrl+_` / `Ctrl+-` | 入力の undo |
| `Ctrl+G` / `Ctrl+X` `Ctrl+E` | **外部エディタ**で入力を編集($EDITOR が開く) |
| `Ctrl+S` | 入力を stash(一時退避) |
| `Ctrl+V` / `Alt+V` | クリップボードの**画像**を貼り付け(WSL は `Ctrl+V`) |
| `Alt+P` | モデルピッカーを開く |
| `Alt+O` | Fast モードのトグル |
| `Alt+T` | 思考(thinking)のトグル |
| `Ctrl+X` `Ctrl+K` | 実行中のエージェントを停止 |
| `Ctrl+]` | Artifact を開く |

### プレフィックス入力

| 先頭に打つ | 動作 |
|---|---|
| `/` | スラッシュコマンド |
| `@` | ファイルパス補完(該当ファイルを直接参照させる) |
| `!` | **シェルモード**。コマンドを実行し出力を会話に取り込む |
| `/btw` | 本筋を止めずに横道の質問をする |

`Tab` で補完を確定、`Esc` で補完を閉じる。

## タスク実行中

| キー | 動作 |
|---|---|
| `Esc` | 実行を中断 |
| `Ctrl+B` / `Ctrl+X` `Ctrl+B` | 実行中のタスクを**バックグラウンドに送る** |
| `Ctrl+O` | 出力の全文(トランスクリプト)を確認 |

バックグラウンド化した会話は「`Enter` で開く · `Esc` で戻る · `Ctrl+C` 2回で終了」。

## トランスクリプト表示中(`Ctrl+O` の中)

vim / less 系の操作が使える。

| キー | 動作 |
|---|---|
| `j` / `k`,`↓` / `↑` | 1行スクロール |
| `Ctrl+D` / `Ctrl+U` | 半ページ送り / 戻し |
| `Ctrl+F` / `Ctrl+B`,`Space` / `b` | 1ページ送り / 戻し |
| `g` / `Shift+G`,`Home` / `End` | 先頭 / 末尾 |
| `Ctrl+E` | 全件表示のトグル |
| `q` / `Esc` / `Ctrl+C` | 閉じる |

|---|---|
| `↑` `↓` / `j` `k` | ファイル移動 |

## 巻き戻し(`Esc` `Esc` → MessageSelector)

| キー | 動作 |
|---|---|
| `↑` `↓` / `j` `k` / `Ctrl+P` `Ctrl+N` | メッセージ選択 |
| `Shift+↑` / `Ctrl+↑` | 一番上へ |
| `Shift+↓` / `Ctrl+↓` | 一番下へ |
| `Enter` | その地点まで巻き戻す |

編集前にファイルのスナップショットを取っているため、**コード・会話・その両方**を選んで復元できる。

## 効率の観点で効くもの

| ショートカット | なぜ効くか |
|---|---|
| `Shift+Tab`(Plan モード) | 実装前に方針を固める。**手戻り = 最大のトークン浪費**を防ぐ |
| `Esc` `Esc`(rewind) | 誤った出力の上に会話を積み上げず、分岐点から取り直せる |
| `Ctrl+O` | 「もう一度出力して」と頼まずに済む = 再生成コストゼロ |
| `Esc`(即中断) | 明らかに違う方向に進み始めたら即止める。最後まで走らせない |
| `Ctrl+G`(外部エディタ) | 長い指示を一発で書ける。短い指示の往復を減らせる |
| `Alt+P` → `←` `→` | タスクの難易度に合わせて effort を上下させる |
| `Ctrl+B` | 長時間タスクを裏に回して別作業を続ける(待ち時間の削減) |
| `@` | 探索させずにファイルを直接指定。無駄な検索トークンを削る |

## カスタマイズ

`~/.claude/keybindings.json` に記述して上書きできる。

```json
{
  "keybindings": [
    {
      "context": "Chat",
      "bindings": { "ctrl+k": "chat:clearInput" }
    }
  ]
}
```

- `context` は `Global` / `Chat` / `Autocomplete` / `Settings` / `Confirmation` /
  `Tabs` / `Transcript` / `HistorySearch` / `Task` / `ThemePicker` / `Scroll` /
  `Help` / `Attachments` / `Footer` / `MessageSelector` / `DiffDialog` /
  `ModelPicker` / `Select` / `Plugin` など
- `Global` はどこでも効く
- 連続打鍵(chord)も可: `"ctrl+x ctrl+e"`

### 再割り当てできないキー
| キー | 理由 |
|---|---|
| `Ctrl+C` | 中断/終了で固定 |
| `Ctrl+D` | 終了で固定 |
| `Ctrl+M` | 端末上 `Enter` と同一(どちらも CR を送る) |
| `CapsLock` | 端末アプリに届かない |

### 端末側の設定
`/terminal-setup` を実行すると、`Shift+Enter`(Mac は `Option+Enter`)での改行や
ホイールスクロール感度など、端末ごとの推奨設定を適用してくれる。
