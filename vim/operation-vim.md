# Neovim 初学者向け操作ガイド

## 0. まず覚える3つ

| やりたいこと | キー |
|---|---|
| 入力をやめる（迷ったらこれ） | `Esc` |
| 保存して終了 | `:wq` → `Enter` |
| 保存せず終了 | `:q!` → `Enter` |

**困ったら `Esc` を2回押す。** それでノーマルモードに戻れる。

起動と終了：

```bash
nvim ファイル名     # 開く（無ければ新規作成）
nvim               # 空で起動
```

---

## 1. モードの概念（ここが最重要）

vim系エディタは「モード」で操作が変わる。文字を打っても入力されないのは、ノーマルモードにいるから。

```
                 i, a, o
   ノーマルモード ─────────→ 挿入モード（文字を打てる）
        ↑  │                      │
    Esc │  │ v                Esc │
        │  ↓                      ↓
   ビジュアルモード ←───────── ノーマルモード
        (範囲選択)

   ノーマルモード ── : ──→ コマンドラインモード（:w, :q など）
```

| モード | 役割 | 入り方 | 抜け方 |
|---|---|---|---|
| ノーマル | 移動・削除・コピー（初期状態） | `Esc` | — |
| 挿入 | 文字を書く | `i` `a` `o` | `Esc` |
| ビジュアル | 範囲を選択する | `v` `V` `Ctrl-v` | `Esc` |
| コマンドライン | 保存・終了・検索 | `:` `/` | `Esc` or `Enter` |

画面左下に `-- INSERT --` と出ていれば挿入モード。何も出ていなければノーマルモード。

---

## 2. 挿入モードへの入り方（使い分け）

| キー | 動き |
|---|---|
| `i` | カーソルの**前**から入力（insert） |
| `a` | カーソルの**後**から入力（append） |
| `I` | 行の**先頭**から入力 |
| `A` | 行の**末尾**から入力 ← よく使う |
| `o` | **下**に新しい行を作って入力 ← よく使う |
| `O` | **上**に新しい行を作って入力 |

> 初学者はまず `i` `A` `o` の3つだけで十分。

## 3. カーソル移動（ノーマルモード）

### 基本

```
        k  (上)
        ↑
 h ←         → l
 (左)   ↓    (右)
        j  (下)
```

矢印キーでも動くが、`hjkl` に慣れるとホームポジションから手が離れない。

### 行内の移動

| キー | 動き |
|---|---|
| `0` | 行頭へ |
| `^` | 行頭の最初の文字へ（インデントを飛ばす） |
| `$` | 行末へ |
| `w` | 次の単語の先頭へ |
| `b` | 前の単語の先頭へ |
| `e` | 単語の末尾へ |

### ファイル内の移動

| キー | 動き |
|---|---|
| `gg` | ファイルの先頭へ |
| `G` | ファイルの末尾へ |
| `42G` または `:42` | 42行目へ |
| `Ctrl-d` | 半画面下へ |
| `Ctrl-u` | 半画面上へ |
| `%` | 対応する括弧へジャンプ |

## 4. 編集の基本

### 削除

| キー | 動き |
|---|---|
| `x` | カーソル位置の1文字を削除 |
| `dd` | 1行削除 ← 最頻出 |
| `3dd` | 3行削除 |
| `dw` | 単語1つ削除 |
| `d$` | カーソルから行末まで削除 |
| `D` | `d$` と同じ |

### コピー＆ペースト

| キー | 動き |
|---|---|
| `yy` | 1行コピー（yank） |
| `3yy` | 3行コピー |
| `yw` | 単語1つコピー |
| `p` | カーソルの**後（下）**に貼り付け |
| `P` | カーソルの**前（上）**に貼り付け |

> vimの削除（`dd` など）は「切り取り」でもある。`dd` → `p` で行の移動ができる。

### 取り消し

| キー | 動き |
|---|---|
| `u` | 元に戻す（undo） |
| `Ctrl-r` | やり直す（redo） |
| `.` | 直前の操作を繰り返す ← 強力 |

### 置換・変更

| キー | 動き |
|---|---|
| `r` + 文字 | 1文字だけ置き換える |
| `cw` | 単語を消して挿入モードへ（change word） |
| `cc` | 行全体を消して挿入モードへ |
| `C` | カーソルから行末を消して挿入モードへ |

## 5. 「動詞 + 対象」という考え方

vimのコマンドは英語の文のように組み合わせる。これが分かると暗記量が激減する。

```
   [回数] + 動詞 + 対象
     3      d      w     → 単語3つ削除
```

**動詞**

| 動詞 | 意味 |
|---|---|
| `d` | delete（削除） |
| `y` | yank（コピー） |
| `c` | change（削除して挿入モードへ） |
| `v` | 選択 |

**対象**

| 対象 | 意味 |
|---|---|
| `w` | 単語 |
| `$` | 行末まで |
| `0` | 行頭まで |
| `ap` | 段落 |
| `i(` | `()` の**中身**（inner） |
| `i"` | `""` の中身 |
| `it` | HTMLタグの中身 |

**組み合わせ例**

| コマンド | 意味 |
|---|---|
| `di"` | ダブルクォートの中身を削除 |
| `ci(` | 括弧の中身を書き換える ← コーディングで多用 |
| `yi{` | `{}` の中身をコピー |
| `dap` | 段落まるごと削除 |
| `cit` | HTMLタグの中身を書き換える |

## 6. 検索と置換

### 検索

| キー | 動き |
|---|---|
| `/word` + `Enter` | 下方向に `word` を検索 |
| `?word` + `Enter` | 上方向に検索 |
| `n` | 次の一致へ |
| `N` | 前の一致へ |
| `*` | カーソル下の単語を検索 |
| `:noh` | 検索結果のハイライトを消す |

### 置換

```vim
:s/old/new/         " その行の最初の1つを置換
:s/old/new/g        " その行のすべてを置換
:%s/old/new/g       " ファイル全体のすべてを置換
:%s/old/new/gc      " 全体を置換（1つずつ確認する）
```

`gc` の確認では `y`（置換する）/ `n`（しない）/ `a`（以降すべて）/ `q`（やめる）で答える。

## 7. ビジュアルモード（範囲選択）

| キー | 動き |
|---|---|
| `v` | 文字単位で選択 |
| `V` | 行単位で選択 ← 分かりやすい |
| `Ctrl-v` | 矩形（ブロック）選択 |

選択したあとに：

| キー | 動き |
|---|---|
| `d` | 削除 |
| `y` | コピー |
| `>` | インデントを下げる（右へ） |
| `<` | インデントを上げる（左へ） |
| `u` / `U` | 小文字化 / 大文字化 |

**よく使う流れ**：`V` → `jjj`（範囲を広げる）→ `d`（削除）

## 8. ファイル操作（コマンドラインモード）

| コマンド | 動き |
|---|---|
| `:w` | 保存 |
| `:w ファイル名` | 名前を付けて保存 |
| `:q` | 終了 |
| `:wq` または `:x` | 保存して終了 |
| `:q!` | 保存せず強制終了 |
| `:wqa` | 全部保存して終了 |
| `:e ファイル名` | 別のファイルを開く |
| `:e!` | 編集を破棄して読み直す |

## 9. 複数ファイル・画面分割

### バッファ（開いているファイル）

| コマンド | 動き |
|---|---|
| `:ls` | 開いているファイル一覧 |
| `:bn` | 次のファイルへ |
| `:bp` | 前のファイルへ |
| `:bd` | 今のファイルを閉じる |

### 画面分割

| コマンド | 動き |
|---|---|
| `:sp` | 上下に分割 |
| `:vs` | 左右に分割 |
| `Ctrl-w` + `hjkl` | 分割した画面を移動 |
| `Ctrl-w` + `q` | 今の画面を閉じる |

## 10. Neovim特有のこと

- 設定ファイルは `~/.config/nvim/init.lua`（vimは `~/.vimrc`）
- Luaで設定が書ける
- ターミナルを内蔵：`:terminal` で起動、ターミナル内で `Ctrl-\` `Ctrl-n` を押すとノーマルモードに戻れる
- LSP（コード補完・定義ジャンプ）が標準で組み込まれている
- プラグイン管理は `lazy.nvim` が定番

最小限の `~/.config/nvim/init.lua` の例：

```lua
vim.opt.number = true          -- 行番号を表示
vim.opt.relativenumber = true  -- 相対行番号（5j などが数えやすい）
vim.opt.expandtab = true       -- Tabをスペースに
vim.opt.shiftwidth = 2         -- インデント幅
vim.opt.tabstop = 2
vim.opt.ignorecase = true      -- 検索で大文字小文字を区別しない
vim.opt.smartcase = true       -- ただし大文字を含めたら区別する
vim.opt.clipboard = "unnamedplus"  -- OSのクリップボードと共有
```

## 11. 練習方法

```bash
nvim +Tutor      # 公式チュートリアル（30分・日本語あり）
```

`:Tutor` はNeovim内から起動してもよい。**まずはこれを1周する**のが一番早い。

### 上達の順序

1. `Esc` / `i` / `:wq` だけで文章を書く
2. `hjkl` で移動する（矢印キーを封印する）
3. `dd` `yy` `p` `u` を使う
4. `w` `b` `0` `$` `gg` `G` で速く移動する
5. `ci(` `di"` などの「動詞＋対象」を覚える
6. `.` で繰り返し、`/` で検索する

## 12. つまずきポイント

| 症状 | 原因と対処 |
|---|---|
| 文字を打っても入力されない | ノーマルモードにいる。`i` を押す |
| 抜けられない・終われない | `Esc` → `:q!` → `Enter` |
| `E37: No write since last change` | 未保存。`:wq` で保存、`:q!` で破棄 |
| 大量の文字が消えた | `u` で戻す。慌てて `:wq` しない |
| `Ctrl-s` で画面が固まった | ターミナルのフロー制御。`Ctrl-q` で解除 |
| コピーがOSに反映されない | `vim.opt.clipboard = "unnamedplus"` を設定する |
| 前のセッションのファイルが残っていると言われる | `.swp` ファイル。`R`（復元）か `D`（削除）を選ぶ |
